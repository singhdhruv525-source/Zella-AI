# Zella Voice brand files

Official files from the Zella Voice design system (4 Nov 2026). Don't retype the wordmark or redraw the bars.

| File | Use |
|---|---|
| `zella-voice-logo-transparent.png` | Full logo, colour, for light backgrounds (original, 4019 x 1600) |
| `zella-voice-logo-white-transparent.png` | Full logo, white letters, for dark backgrounds (original) |
| `zella-wordmark-transparent.png` | Wordmark only, for spaces under 160px wide (original) |
| `zella-two-bars.svg` | The two-bar symbol on its own (collapsed sidebar, loaders) |
| `zella-voice-icon.svg` | App icon |
| `zella-voice-logo-sidebar.png`, `-white.png` | The two full logos cropped to their visible edges and scaled to 96px tall for the sidebar. Same pixels, nothing redrawn. |

The bars in `zella-two-bars.svg` have exactly the proportions of the bars inside the full logo, so the sidebar
lays the symbol over the logo's own bars: in the cropped sidebar logo they start 28.25% from the left
(873 of 3090 px) and are 50/99 as wide as they are tall.
